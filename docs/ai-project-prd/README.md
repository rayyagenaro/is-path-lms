# IS-Path AI Project PRD Pack

This folder is the consolidated product handoff for IS-Path. It combines the intent from PRD v1, PRD v2, the final LMS PRD, the ontology draft, the implemented Laravel/PostgreSQL application, and the RDF/SWRL integration state.

Start here:

1. `00-master-prd.md` - product direction, scope, flows, requirements, and acceptance criteria.
2. `01-implementation-state.md` - what already exists in the codebase and how the app is wired.
3. `02-ontology-and-reasoning.md` - ontology role, RDF/SWRL bridge, rule usage, and data mapping.
4. `03-roadmap-and-gaps.md` - remaining work, risks, and recommended next implementation steps.
5. `04-ai-working-contract.md` - constraints for future AI agents working on this project.

Original source documents are kept in `sources/`:

- `prd-v1-competency-based-lms.md`
- `prd-v2-is-path.md`
- `prd-final-lms.md`
- `ontology-draft.md`
- `ontology-integration.md`
- `design-system.md`
- `LMS-FIX.rdf`

Do not treat the source files as the latest single source of truth by themselves. The consolidated files above reconcile them with the current implementation.
